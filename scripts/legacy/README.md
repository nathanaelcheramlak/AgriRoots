# Retired frontend tooling

Use [current setup](../../docs/getting-started.md) and the sibling frontend's Home guide. Restore the historical frontend and tooling from the same Git revision in a separate checkout if reproducing old evaluation results. Existing backend advisory execution/review/release remains intact, but the newer frontend does not yet expose all of the retired UI's farmer and administration screens.
